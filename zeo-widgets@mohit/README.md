# Zeo-Style Widgets

Zeo-style desktop widgets for GNOME Shell. Currently provides a floating system monitoring card with a macOS-inspired design.

## Features
- CPU, Memory, and Disk usage rings
- GPU utilization monitoring (auto-detects Intel and NVIDIA GPUs)
- Smooth UI and animations
- Polished macOS-style design with blur effects
