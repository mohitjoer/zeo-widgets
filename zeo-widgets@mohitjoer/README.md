# Zeo System Monitor

A high-performance, Astra-inspired system monitoring extension for the GNOME top bar panel.

## Features
- **Top Bar Indicators**: Real-time status in GNOME panel for CPU %, Memory (RAM), GPU %, Disk usage, Network speed (Upload / Download), and Temperature sensors.
- **Rich Dropdown Dashboard**:
  - **Overview**: System host summary, uptime, and visual progress cards.
  - **CPU**: Utilization progress, CPU clock frequency, load averages, per-core utilization grid, and top CPU processes table.
  - **Memory & Swap**: RAM and Swap breakdown (Used / Available / Cached / Total) and top memory-consuming processes.
  - **Storage**: Real-time Disk I/O read/write rates and per-partition capacity meters.
  - **Network**: Real-time upload and download throughput and active interface data counters.
  - **Sensors**: CPU package, core temperatures, GPU, disk temps, and fan speeds.
- **Preferences**: Fully customizable toggles, panel placement (Left / Center / Right), update intervals, and units.
- **Aesthetic**: Premium minimalist macOS/Zeo monochrome styling with dynamic dark & light theme support.
