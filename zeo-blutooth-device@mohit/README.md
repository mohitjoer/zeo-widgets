# Zeo Bluetooth Device

Zeo-style desktop widget for GNOME Shell. It provides a floating monitor for connected Bluetooth devices and their battery charges.

## Features
- Real-time Bluetooth device battery monitoring
- Dynamic color rings (green/blue/red based on battery level)
- Drag-and-drop floating design
- Smooth macOS-inspired glassmorphism styling
